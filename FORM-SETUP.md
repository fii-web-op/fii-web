# Форма «Оставить заявку» → Google-таблица

Заявки с сайта (ФИО, телефон, почта) отправляются в Google-таблицу через
Google Apps Script Web App. Это работает без бэкенда — прямо со статических
страниц.

Таблица: <https://docs.google.com/spreadsheets/d/1QXnXXSfA2s-pzLg37R-YbUTCI_k_MCKq4uEmfpCCvVg/edit>

## Шаги подключения

1. Откройте таблицу → меню **Расширения → Apps Script**.
2. Удалите содержимое `Code.gs`, вставьте код из файла
   [`google-apps-script.gs`](./google-apps-script.gs) и сохраните (Ctrl+S).
3. Нажмите **Развернуть → Новое развёртывание**.
   - Тип: **Веб-приложение**.
   - **Запуск от имени:** «Я» (владелец таблицы).
   - **У кого есть доступ:** «Все» (`Anyone`).
4. Подтвердите доступ к таблице (Google запросит авторизацию при первом деплое).
5. Скопируйте **URL веб-приложения** — он выглядит так:
   `https://script.google.com/macros/s/XXXXXXXX/exec`
6. Откройте [`script.js`](./script.js) и вставьте этот URL в константу:

   ```js
   const APPLY_ENDPOINT = 'https://script.google.com/macros/s/XXXXXXXX/exec';
   ```

7. Сохраните и задеплойте сайт. Готово — заявки начнут падать в лист «Заявки».

## Как это устроено

- Фронтенд отправляет `POST` с JSON-телом в режиме `no-cors`
  (`Content-Type: text/plain`), потому что Apps Script не отдаёт CORS-заголовки.
  Запись в таблицу проходит, но ответ скрипта браузером не читается — поэтому
  при успешном `fetch` форма показывает сообщение об успехе.
- Скрипт `doPost` дописывает строку: дата, ФИО, телефон, email, страница.
- Если листа «Заявки» нет — он создаётся автоматически с заголовками.

## Важное про закон

В футере каждой страницы выводится уведомление об обработке персональных данных
(152-ФЗ): оператор, цели обработки, срок, право на отзыв согласия. Перед
публикацией замените плейсхолдеры на реальные реквизиты:

- Полное наименование и адрес оператора (РУДН / факультет).
- Контактный e-mail для отзыва согласия (сейчас `admission@ai-faculty.ru`).

> Если потребуется отдельная страница «Политика обработки персональных данных»,
> её можно вынести в отдельный HTML и заменить якорь `#data-policy` на ссылку.
